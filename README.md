# Asri Energy Landing Page

A responsive landing page for **Asri Energy**, a renewable energy solutions company. Built with a focus on clean design, usability, and performance.

## Features

- Responsive layout using Tailwind CSS  
- Service slider, testimonials, FAQ, and contact form  
- Scroll reveal animations using Intersection Observer  
- Navigation bar with scroll-based style changes  

## Demo

- [**Behance Design Preview**](https://www.behance.net/gallery/250137685/Asri-Energy-Website)
- [**Live Demo**](https://mrezadit.github.io/asri-energy-landing-page/) 

## Tech Stack

- HTML5  
- Tailwind CSS (CDN)  
- JavaScript (ES6+)  
- Fontshare (General Sans)

## Setup

1. Clone or download this repository  
2. Open `index.html` in your browser  
3. Ensure asset folders (if any) are properly included
